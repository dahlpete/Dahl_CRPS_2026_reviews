This directory contains the code necessary to compute the Fisher information matrix, covariance matrix, and correlation matrix for the fit to the NC2:MoFe protein dataset. The directory "r0/" contains the simulation with unperturbed fit parameters, and the rest of the directories "r1/" to "r10/" contain simulations in which one of the fit parameters is perturbed. The simulations in these directories were run separately, and the calculation of the matrix was completed by running the script construct_matrices.py.
